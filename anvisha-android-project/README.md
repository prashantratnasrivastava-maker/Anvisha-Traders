# Anvisha Traders - Android Studio Project (Google Play Store Ready)

Yeh complete native Android project hai jise aap **Google Play Store** par dalne ke liye use kar sakte hain.

## 🛠️ How to Generate `.aab` / `.apk` in 2 Minutes:

1. Apne computer/laptop par **Android Studio** (free download) open karein.
2. **Open Project** par click karein aur is unzipped folder ko select karein.
3. Android Studio dependencies ko 30 seconds mein sync karega.
4. Top menu se click karein:
   👉 **Build ➔ Generate Signed Bundle / APK...**
5. Select karein **Android App Bundle (.aab)** (Google Play Store ke liye yeh mandatory hota hai).
6. Naya KeyStore banayein (ya apna password dalein) aur **Finish** dabayein!
7. Aapko Play Store upload ke liye ready `.aab` file mil jayegi!

## 📦 App Details:
- **Package Name:** `com.anvishatraders.app`
- **Target SDK:** 34 (Latest Android 14 / Google Play Store 2024-2026 requirement)
- **Min SDK:** 21 (Supports 99.8% of Android devices)
- **Features Included:**
  - Pull-to-refresh
  - Loading bar
  - WhatsApp & Phone call intent support (Direct click to call/chat)
  - Full screen native feel without browser url bar
  - Back button navigation support
